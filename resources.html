Student Resources

Lab Safety Essentials

  • Wear PPE: goggles, coat, gloves.
  • Label all containers clearly.
  • Follow waste segregation rules.

Practice Workflow

  • Solve by topic first.
  • Move to mixed papers later.
  • Track mistakes in error notebook.

Memory Tools

  • Flashcards for reagents.
  • Mechanism maps for pathways.
  • Weekly spaced revision cycles.

Quick FAQ (Interactive)

How do I start Organic from zero?

Start with structure + bonding + acidity. Then move to functional groups and mechanisms.

How to remember named reactions?

Create 1-page maps by reaction family and revise using spaced repetition every 3-4 days.

Best order to solve unknown spectroscopy problems?

Use MS for mass, IR for functional groups, then NMR for final structure assembly.
